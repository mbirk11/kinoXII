# KINO XII

Cinema chain ticket-booking app built for Redberry Bootcamp XII.
Users browse films, pick a session in one of four venues, choose seats and buy tickets.

## Tech

- React 19 + Vite
- API: https://api.kinoxii.redberryinternship.ge/api

## Getting started

```bash
npm install
npm run dev
```

## Scripts

- `npm run dev` – start the dev server
- `npm run build` – production build
- `npm run lint` – run ESLint
- `npm run preview` – preview the production build
